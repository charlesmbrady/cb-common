# Knight Model Placement

Place the downloaded Sketchfab model file at:

`apps/apps/public/subapps/3DPhysicsSandbox/models/knight-low-poly.glb`

Expected runtime URL:

`/subapps/3DPhysicsSandbox/models/knight-low-poly.glb`

The `Knight Model Scene` in the 3D Physics Sandbox loads this file directly.
